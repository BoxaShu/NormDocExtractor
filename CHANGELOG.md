# Changelog

Все заметные изменения в проекте `NormDocExtractor` документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект придерживается [семантического версионирования](https://semver.org/lang/ru/).

## [Unreleased]

### Планируется
- Закладки в исходном документе для перехода к конкретному упоминанию

## [1.0.0] — 2026-10-21

Первый публичный релиз.

### Добавлено

#### Извлечение нормативных документов
- Распознавание 12+ типов нормативных документов в тексте Word-документа:
  `ГОСТ`, `ГОСТ Р`, `ГОСТ ИСО/МЭК`, `СНиП`, `СП`, `СанПиН`, `ТУ`, `РД`, `ВСН`,
  `МДС`, `СТО`, `НПБ`, `ПБ`, `ПУЭ`, `ФЗ`.
- Нормализация текста перед разбором: замена неразрывных пробелов (`\u00A0`),
  удаление мягких переносов (`\u00AD`), склейка разрывов строк и табуляций.
- Подсчёт общего числа упоминаний и количества уникальных документов.
- Сортировка результата по алфавиту без учёта регистра.

#### Отчёт-таблица
- Генерация нового документа Word с таблицей из 5 колонок:
  «№ п.п.», «Номер документа», «Сколько упоминаний»,
  «Проверить на etr-torgi.ru», «Проверить на protect.gost.ru».
- Заголовок таблицы с выделением жирным и серой заливкой.
- Автоподбор ширины колонок (`Table.Columns.AutoFit`).

#### Ссылки для проверки статуса
- Прямая ссылка на `etr-torgi.ru` через GET-параметр `?query_light=`
  (работает для любых типов документов).
- Прямая ссылка на `protect.gost.ru` с автоматическим выбором раздела:
  `/gost` для ГОСТ и `/sp` для СП.
- Корректное URL-кодирование номеров с кириллицей и пробелами
  (`Uri.EscapeDataString`).
- Прочерк `—` в ячейке для типов документов, не поддерживаемых `protect.gost.ru`.

#### Замена устаревших номеров
- Диалог замены, открывающийся **двойным кликом** по номеру документа в отчёте.
- Поле `txtOld` (старый номер) — только для чтения.
- Поле `txtNew` (новый номер) — предзаполнено старым номером без двух
  последних символов (обычно год).
- Кнопка «Заменить всё» блокируется, пока пользователь не допишет год
  новой версии (проверка: минимум 2 цифры в конце строки).
- Массовая замена всех вхождений через `Find.Replace` с
  `WdReplace.wdReplaceAll`.
- Подсчёт вхождений перед заменой и подтверждение действия
  с указанием количества.
- Автоматическое обновление строки в отчёте после замены с пометкой
  «(было: …)» серым курсивом.
- Сохранение первоначального номера при повторных заменах —
  пометка не накапливается.

#### Интеграция с Word
- Кнопка «Извлечь нормативы» на отдельной вкладке `NormDocExtractor`
  ленты Word.
- Хранение пути к исходному документу в
  `CustomDocumentProperties` отчёта (`NormExtract_SourcePath`).
- Обработчик `Application.WindowBeforeDoubleClick` для перехвата двойного
  клика в таблице отчёта.
- Отложенное открытие диалога через `System.Windows.Forms.Timer` —
  устраняет зависание при повторных кликах.
- Возврат фокуса в отчёт после закрытия диалога замены
  (`Document.Activate`).

#### Устойчивость и надёжность
- Проверка «клик в таблице» через `Selection.Information[wdWithInTable]`.
- Определение столбца «Номер документа» по тексту заголовка,
  а не по индексу — устойчиво к вставке/удалению столбцов.
- Защита от замены в несохранённом документе — предупреждение в шапке
  отчёта, ссылки на закладки отключаются.
- Обработка ошибок: диалоговые окна с понятными сообщениями вместо
  необработанных `COMException`.

### Изменено
- Отказ от сетевых провайдеров статуса (`gostcheck.ru`, `etr-torgi.ru` API)
  в пользу генерации прямых ссылок — решение проблем с HTTP 405,
  TLS-согласованием и нестабильностью неофициальных API.

### Удалено
- `INormStatusProvider` и реализующие его классы.
- `GostCheckStatusProvider`, `EtrTorgiStatusProvider`, `FallbackStatusProvider`.
- Зависимость от `System.Text.Json` и его транзитивных пакетов.
- Зависимость от `Newtonsoft.Json`.

### Исправлено
- Двойной клик по номеру документа во второй раз не открывал диалог
  замены (замороженный `Selection` из-за `Cancel = true`).
- `GetReportSourcePath` возвращал `null` при использовании
  `Word.Variables` — заменено на `CustomDocumentProperties`.
- Ограничение 255 символов на значение в `Word.Variables` —
  обойдено переходом на `CustomDocumentProperties`.

### Безопасность
- Проект распространяется под лицензией **GNU GPL v3.0**.
- Все исходные файлы содержат заголовок с указанием авторства
  и условий лицензии.
- Настройка `SecurityRules(SecurityRuleSet.Level1)` для совместимости
  с VSTO-моделью безопасности.

- **Добавлено** — новая функциональность.
- **Изменено** — изменения в существующей функциональности.
- **Устарело** — функции, которые будут удалены в следующих версиях.
- **Удалено** — удалённая функциональность.
- **Исправлено** — исправления ошибок.
- **Безопасность** — изменения, связанные с уязвимостями.
