Плагин для Microsoft Word, который извлекает из документа все упоминания нормативных документов (ГОСТ, СНиП, СП, СанПиН, ТУ, РД, ВСН, МДС, СТО, НПБ, ПБ, ПУЭ, ФЗ), формирует удобный отчёт-таблицу и позволяет быстро проверять актуальность и заменять устаревшие номера прямо из отчёта.

## 🎯 Зачем это нужно

Инженеры, проектировщики, специалисты ПТО и технические писатели регулярно сталкиваются с задачей: в документе (пояснительной записке, отчёте, регламенте) упоминаются десятки нормативных документов — и надо убедиться, что все они актуальны. Вручную это занимает часы.

`NormDocExtract` сокращает эту работу до пары кликов:

- Находит в тексте **все** нормативные ссылки, включая повторные упоминания.
- Показывает, сколько раз каждый документ встречается.
- Даёт готовые ссылки на проверку статуса на `etr-torgi.ru` и `protect.gost.ru`.
- Позволяет заменить устаревший номер **во всех местах документа** одним действием.

## ✨ Возможности

- 🔍 **Распознавание 12+ типов нормативных документов**
  ГОСТ, ГОСТ Р, ГОСТ ИСО/МЭК, СНиП, СП, СанПиН, ТУ, РД, ВСН, МДС, СТО, НПБ, ПБ, ПУЭ, ФЗ.
- 📊 **Отчёт-таблица в новом документе Word**
  С номерами, количеством упоминаний и готовыми ссылками для проверки.
- 🌐 **Быстрая проверка статуса в один клик**
  `etr-torgi.ru` — для любых документов; `protect.gost.ru` — для ГОСТ и СП (с автоматическим выбором раздела `/gost` или `/sp`).
- ✏️ **Замена номера во всех вхождениях**
  Двойной клик по номеру в отчёте → диалог замены → новый номер применяется ко всем упоминаниям в исходнике. Отчёт автоматически обновляется с пометкой `(было: …)`.
- 🛡 **Защита от случайной замены**
  Кнопка «Заменить всё» блокируется, пока пользователь не допишет год новой версии.
- 🚀 **Работает без интернета**
  Вся логика — локальная. Внешние ссылки открываются в браузере по требованию, сам плагин не обращается к сети.

## 🛠 Установка

### Требования

- Microsoft Word 2016 / 2019 / 2021 / Microsoft 365 (Windows).
- .NET Framework 4.8 (устанавливается вместе с Word 2019+, для Word 2016 — [скачать отдельно](https://dotnet.microsoft.com/download/dotnet-framework/net48)).
- Права администратора при установке (VSTO требует установки в `%LOCALAPPDATA%` или `Program Files`).

### Способ 1: Установщик (рекомендуется)

1. Скачайте последний релиз со страницы [Releases](../../releases).
2. Запустите `NormExtractSetup.msi` и следуйте инструкциям.
3. Откройте Word — на ленте появится вкладка **NormExtract**.
