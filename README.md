# NormDocExtractor

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)
[![.NET Framework](https://img.shields.io/badge/.NET%20Framework-4.8-purple.svg)](https://dotnet.microsoft.com/)
[![Platform](https://img.shields.io/badge/Platform-Word%202016%2B-green.svg)](https://www.microsoft.com/microsoft-365/word)

Плагин для Microsoft Word, который извлекает из документа все упоминания нормативных документов (ГОСТ, СНиП, СП, СанПиН, ТУ, РД, ВСН, МДС, СТО, НПБ, ПБ, ПУЭ, ФЗ), формирует удобный отчёт-таблицу и позволяет быстро проверять актуальность и заменять устаревшие номера прямо из отчёта.

## Зачем это нужно

Инженеры, проектировщики, специалисты ПТО и технические писатели регулярно сталкиваются с задачей: в документе (пояснительной записке, отчёте, регламенте) упоминаются десятки нормативных документов — и надо убедиться, что все они актуальны. Вручную это занимает часы.

`NormDocExtractor` сокращает эту работу до пары кликов:

- Находит в тексте **все** нормативные ссылки, включая повторные упоминания.
- Показывает, сколько раз каждый документ встречается.
- Даёт готовые ссылки на проверку статуса на `etr-torgi.ru` и `protect.gost.ru`.
- Позволяет заменить устаревший номер **во всех местах документа** одним действием.

## Возможности

- 🔍 **Распознавание 12+ типов нормативных документов**
  ГОСТ, ГОСТ Р, ГОСТ ИСО/МЭК, СНиП, СП, СанПиН, ТУ, РД, ВСН, МДС, СТО, НПБ, ПБ, ПУЭ, ФЗ.

- 📊 **Отчёт-таблица в новом документе Word**
  С номерами, количеством упоминаний и готовыми ссылками для проверки.

- 🌐 **Быстрая проверка статуса в один клик**
  `etr-torgi.ru` — для любых документов; `protect.gost.ru` — для ГОСТ и СП (с автоматическим выбором раздела `/gost` или `/sp`).

- ✏️ **Замена номера во всех вхождениях**
  Двойной клик по номеру в отчёте → диалог замены → новый номер применяется ко всем упоминаниям в исходнике. Отчёт автоматически обновляется с пометкой `(было: …)`.

- 🛡 **Защита от случайной замены**
  Кнопка «Заменить всё» блокируется, пока пользователь не допишет год новой версии.

- 🚀 **Работает без интернета**
  Вся логика — локальная. Внешние ссылки открываются в браузере по требованию, сам плагин не обращается к сети.

## Установка

### Требования

- Microsoft Word 2016 / 2019 / 2021 / Microsoft 365 (Windows).
- .NET Framework 4.8 (устанавливается вместе с Word 2019+, для Word 2016 — [скачать отдельно](https://dotnet.microsoft.com/download/dotnet-framework/net48)).

## Сборка из исходников

### Что понадобится

- **Visual Studio 2022** (Community, Professional или Enterprise) с рабочей нагрузкой **«Разработка Office/SharePoint»** (Office/SharePoint development). Без неё вы не увидите VSTO-шаблоны проектов.
- **.NET Framework 4.8 Developer Pack** — [скачать](https://dotnet.microsoft.com/download/dotnet-framework/net48).
- **Git** — [скачать](https://git-scm.com/downloads).

### Шаги

1. **Клонируйте репозиторий:**

   ```bash
   git clone https://github.com/BoxaShu/NormDocExtractor.git
   cd NormDocExtractor
   ```

2. **Откройте решение в Visual Studio:**

   Двойной клик по `NormDocExtractor.sln` или `File → Open → Project/Solution`.

3. **Восстановите NuGet-пакеты** (если потребуется):

   Правый клик по решению → **Restore NuGet Packages**.

4. **Соберите решение:**

   - Debug: `Ctrl+Shift+B` (или `Build → Build Solution`).
   - Release: переключите конфигурацию на **Release** и повторите сборку.

5. **Запустите с отладкой** (`F5`) — Visual Studio автоматически запустит Word с подключённым плагином. На ленте появится вкладка **NormDocExtractor**.

### Публикация

1. Правый клик по проекту `NormDocExtractor` → **Publish** (или `Build → Publish NormDocExtractor`).
2. Настройте профиль публикации:
   - **Target**: `Disk` (для локальной установки) или `Web` (для ClickOnce).
   - **Publisher name**: `<Ваше Имя>`
   - **Support URL**: `https://github.com/BoxaShu/NormDocExtractor/issues`
   - **Product name**: `NormDocExtractor`
3. Нажмите **Publish** — в указанной папке появятся `setup.exe`, `NormDocExtractor.vsto` и файлы для развёртывания.

### Сертификат подписи

Для распространения плагина за пределы своего компьютера нужен сертификат подписи. Подробно — в документации [VSTO signing](https://learn.microsoft.com/visualstudio/vsto/how-to-sign-office-solutions).

Для локальной разработки достаточно самоподписанного сертификата, создаваемого Visual Studio автоматически.

## Использование

1. Откройте документ Word, в котором нужно найти нормативные ссылки.
2. Перейдите на вкладку **NormDocExtractor** → нажмите **«Извлечь нормативы»**.
3. Откроется новый документ с таблицей:

   | № п.п. | Номер документа | Сколько упоминаний | etr-torgi.ru | protect.gost.ru |
   |---|-------------------|---|-----------|-----------|
   | 1 | ГОСТ 12.1.005-88  | 3 | Открыть → | Открыть → |
   | 2 | СП 131.13330.2025 | 1 | Открыть → | Открыть → |
   | 3 | СНиП 2.01.07-85*  | 2 | Открыть → | —         |

4. **Клик по «Открыть →»** — откроется страница проверки статуса в браузере.
5. **Двойной клик по номеру документа** — откроется диалог замены:
   - Старый номер показан только для чтения.
   - Новый номер предзаполнен (без последних 2 символов — обычно года).
   - Допишите год вручную, нажмите «Заменить всё» — номер обновится **во всех местах** исходного документа.
   - Отчёт автоматически обновится с пометкой `(было: …)`.

### Типичный сценарий

1. Пользователь открывает проектную документацию на 50 страниц.
2. Нажимает «Извлечь нормативы» — получает список из 30 уникальных документов с 120 упоминаниями.
3. Видит в отчёте, что `ГОСТ 12.1.005-88` отменён (проверяет по ссылке).
4. Двойной клик по номеру → вводит `ГОСТ 12.1.005-2021` → «Заменить всё».
5. Все 3 упоминания в исходнике обновлены, отчёт помечен `(было: ГОСТ 12.1.005-88)`.
